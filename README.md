# جدول لقاءات سنابل

صفحة واحدة (`index.html`) تعرض مواعيد اللقاءات بتوقيت مدينة الطالب. أوقات اللقاءات مسجلة بتوقيت مكة المكرمة.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `sanabil` (يجب أن يكون Public).
2. ارفع ملفات هذا المجلد إلى جذر المستودع.
3. من **Settings ← Pages** اختر **Deploy from a branch**، ثم `main` و`/ (root)`، واضغط Save.
4. بعد دقائق تعمل الصفحة على `https://USERNAME.github.io/sanabil/`.

## تعديل اللقاءات
افتح `index.html` وابحث عن السطر الذي يبدأ بـ `var LESSONS=`. كل لقاء بهذا الشكل:

```js
{title:"اسم اللقاء",dow:3,time:"20:30",mins:60}
```

- `dow`: اليوم بتوقيت مكة: الأحد `0`، الاثنين `1`، الثلاثاء `2`، الأربعاء `3`، الخميس `4`، الجمعة `5`، السبت `6`.
- `time`: الساعة بنظام 24 ساعة بتوقيت مكة (مثل `16:30` أو `06:30`).
- `mins`: المدة بالدقائق.
- افصل بين اللقاءات بفاصلة.

اللقاءات التي يضيفها الطالب من نموذج "أضف لقاءً" تُحفظ في متصفحه فقط ولا تظهر لغيره.
